## Назначение

Модуль предназначен для выполнения следующих операций:
 
  * очистка (dh_clean);
  * настройка (dh_auto_configure);
  * сборка (dh_auto_build);

### Очистка

Выполняется команда

    eng/tools/build.sh --clean

### Настройка

Модифицируется файл `global.json`:

 1. `sdk.rollForward` присваивается `latestMinor`;
 2. `tools.dotnet` заменяется на версию уставленной .Net SDK;
 3. `tools.runtimes` удаляется;
 4. `native-tools` удаляется.

После модификации `global.json` запускается команда

    eng/tools/build.sh -c Release --restore

### Сборка

Выполняется команда

    eng/tools/build.sh -c Release --restore --build

### Дополнительные параметры

Ко всем операциям dh можно добавить дополнительные аргументы, например:

    %:
            dh $@

    override_dh_auto_build:
            dh_auto_build -- --sign -p:Version=1.0

## Использование

Модуль применяется системой Debhelper. Debhelper выбирает систему сборки на основании некоторых
условий. Условием для выбора данного модуля является наличие файла `eng/common/build.sh` в
каталоге исходного кода.
